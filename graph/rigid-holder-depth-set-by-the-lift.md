**Why choose it.** The pen is clamped rigidly and the lift moves it to a set height, so the pressure is set by how far it is pushed down. Exact control of a brush's contact width and of how a pencil bites.

**Tradeoffs.** Every bump or change of thickness in the media changes the pressure, so it needs a flat, levelled surface.

**Links.** It requires the Z-axis stepper lift: only a lift with position control over a range can set a depth. A solenoid has two positions, and a servo's angle is too coarse.
